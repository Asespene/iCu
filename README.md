# iCu

A hands-on workspace documenting my journey learning C from first principles, hardware-level computing fundamentals, and systems programming.

---

## 🎯 About This Repository

This repository tracks practical implementations, exercises, and standalone mini-projects exploring C at both the software and hardware boundary. The primary goal is to build deep, mechanical intuition for:
- Writing clean, robust, and standards-compliant C.
- Understanding how software maps directly to underlying hardware registers, memory hierarchies, and processor architectures.
- Developing modular, verifiable utilities and low-level tools from scratch.

---

## 🧭 Core Focus Areas

- **C Fundamentals & Idioms:** Syntax, types, control flow, modular compilation, and standard library mechanics.
- **Pointers & Memory Architecture:** Pointer arithmetic, stack vs. heap dynamics, memory alignment, padding, and manual lifecycle management.
- **Hardware & Low-Level Interfaces:** Bitwise manipulation, bit-masking, endianness, hardware registers, and embedded-oriented patterns.
- **Mini-Projects:** Self-contained C utilities, data structures, and peripheral/hardware driver simulations.
